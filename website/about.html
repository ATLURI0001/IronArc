About IronArc

An IronArc distribution maintained by Ramprasad Atluri.

This repository builds on the existing openGym project and includes guided workouts, body-weight tracking, passkey profiles, self-hosting, native mobile projects, and an optional AI Coach. Original copyright and third-party notices are retained in NOTICE.md.

The repository links, support destinations, mobile application identifiers, and distribution setup have been adapted for this maintainer.

Principles

  • Your data is yours. Local-first, one-file backups, no lock-in — leaving IronArc must always be one export away.
  • No telemetry, ever. If a feature needs analytics to justify itself, it doesn't ship.
  • Dependency-light. The app uses a Node backend and React frontend; source and dependency manifests are available in the repository.
  • Open source that stays open. AGPL-3.0, so every fork and every hosted version owes its code back to everyone.
